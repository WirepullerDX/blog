# 关于我 / About Me

我是 **阿杰**，熟悉的朋友也会叫我**杰哥**，英文 ID 常用 **WirepullerDX**。

比起「折腾」，我更愿意把这件事叫做**运维一套属于自己的基础设施**：一台 NAS 是数据中心，Docker 是软件分发方式，VPS 是随时可以丢弃的实验田，网络与代理是把这些串起来的链路。时间久了，几块硬盘、几台机器和一堆容器，就长成了一个能自洽运转的小型自托管平台——有存储、有入口、有监控，也有备份和恢复预案。

## 我在折腾什么

- **存储与数据**：以 NAS 为核心做容量规划、快照与异地备份。也完整写过一套前后端分离的相册管理系统，从接口设计到前端交互都自己落地——数据握在自己手里，才谈得上长期主义。
- **容器化与部署**：用 Docker / Compose 把服务拆成可复现的单元，配置纳入版本管理；在 VPS 上跑过反向代理、数据库和定时任务，动手之前先想清楚怎么回滚。
- **网络**：内网分层、反向代理、DNS 与分流策略，代理链路按需编排。比起「能通」，更在意路径可解释、故障可定位。
- **自动化**：部署并长期维护过群聊机器人，把重复的通知、查询和记录交给机器去做。
- **边缘部署**：静态优先，能放在边缘的绝不回源；动态能力交给 Serverless 兜底，成本和弹性都可控。

## 开发与 AI

- **安卓开发**：写过原生应用，熟悉移动端的生命周期、网络请求与本地持久化这一套。
- **AI 图像工作流**：用 ComfyUI 搭过生成流水线，理解节点编排、模型选择与参数调优之间的取舍。
- **Agent 与 LLM**：日常用 Agent 承接重复劳动，也清楚大模型的边界——什么时候可以信任它，什么时候必须自己验证。
- **Vibe coding**：习惯先用自然语言把需求讲清楚，让模型产出可运行的原型，最后自己收口。

## 学过的底子

机器学习、数据挖掘、算法与数据结构都有系统学习。谈不上精通，但遇到问题时知道该往哪个方向找答案——这比背下结论更有用。

## 关于本站

本站是一个**纯边缘托管**的静态站点，没有传统意义上的服务器：

- 框架：Astro + [Firefly](https://github.com/CuteLeaf/Firefly)（基于 [Fuwari](https://github.com/saicaca/fuwari)）
- 托管：Cloudflare Pages，全站构建期静态生成
- 评论：Twikoo 2.0，运行在 Workers 上，数据落在 D1
- 图片：Cloudflare R2，自定义域名加边缘缓存
- 搜索：Pagefind，构建时生成索引

这里写的大多是上面那些折腾的踩坑记录与阶段性总结。如果恰好能帮你少走一点弯路，那它的价值就远超一个备忘录了。
