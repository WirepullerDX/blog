## 项目简介

这是一个以《原神》角色神里绫华为主题的私人动态表情包项目，采用「花时来信」皮肤造型，整体风格偏 VTuber 表情包。

项目使用 `manifest.json` 描述资源结构，当前版本为 `1.0.0`，包含：

- 190 个动态 GIF
- 18 个情绪分类
- 统一的分类、标签和文件清单
- 可直接用于支持自定义表情包的聊天工具或机器人

## 分类设计

表情覆盖日常聊天的常见场景，包括开心、难过、生气、害羞、惊讶、困惑、睡觉、点赞、工作、吃饭、音乐、游戏、问候、思考、装酷、摸头和闲置等。

每个分类都带有用途说明，方便按语境检索，而不是只能从文件名里猜表情含义。

## 使用方式

1. 打开 GitHub 仓库并下载整个项目。
2. 读取根目录的 `manifest.json`。
3. 根据 `categories` 中的分类和描述选择表情。
4. 将需要使用的 GIF 导入支持自定义表情的客户端。

> 这是个人使用的表情包项目，使用前请自行确认相关素材的适用范围。
