# 博客媒体素材

1. 按场景查看 [图片写入规则](../../../docs/WRITING_GUIDE.md#510-图片写入规则) 或 [相册与 R2 指南](../../../docs/WRITING_GUIDE.md#9-相册与-r2)。文章封面通常跟文章放在同一目录，正文大图使用现有 R2 地址。编辑相册时同时核对 [相册配置](../../../src/config/galleryConfig.ts) 和对应的 `public/gallery/<album-id>/`。
2. 优化现有图前，先核对调用位置、实际显示尺寸、源尺寸、透明度和复用场景。按调用场景决定缩放或重编码，验收时记录处理前后的尺寸和字节数。替换公开资源时核对所有相关引用。
3. 准备 R2 素材时，按指南确认对象键、类型和缓存策略。已有上传授权时执行对应上传，并用普通 `GET` 验证公开 URL 和响应头。只完成本地准备时，列出待上传文件和目标对象键。
4. 对会随站点渲染的改动，用实际页面或生产预览核对图片能否加载、比例和透明度是否符合预期。需要完整构建或预览时参照 [blog-release](../blog-release/SKILL.md)。
